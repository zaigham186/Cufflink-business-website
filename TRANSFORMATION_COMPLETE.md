## 🎬 Animation Patterns

### Hero Entrance (Cinematic)
```javascript
Duration: ~2.5s total
1. Background establishes (instant)
2. Image clip-path reveal (1.2s)
3. Title fade-up (1s, -0.6s delay)
4. Subtitle fade-up (0.8s, -0.5s delay)
5. CTAs fade-up (0.8s, -0.4s delay)
6. Brass line scale (1s, -0.6s delay)
```

### Scroll Reveals (One-time)
```javascript
Initial: { y: 60, opacity: 0 }
Animate: { y: 0, opacity: 1 }
Duration: 1s
Easing: power3.out
Trigger: 70% viewport
```

### Product Hovers
```javascript
Image scale: 1 → 1.05 (700ms ease-out)
Brass line: width 0 → 100% (500ms ease-out)
Border opacity: 20% → 60% (300ms)
```
